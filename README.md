# fiap-ai-labs

Projetos de laboratório e estudo em IA/LLM desenvolvidos durante o MBA em Cloud Engineering & Architecture (FIAP).

## Estrutura

- **rag-memory-agent/** — Agente RAG com memória de longo prazo, chunking, embeddings e ChromaDB.
- **llm-gateway-router/** — Gateway/router de prompts com integração Vertex AI, telemetria e auditoria de intenção.

Cada subprojeto possui seu próprio README com instruções específicas de setup e execução.
